# Pulse Player

A responsive static music player built with HTML, CSS, and JavaScript.

## Files

- `index.html` - page structure
- `styles.css` - dark theme, layout, and animations
- `script.js` - playlist, playback controls, seeking, autoplay, and volume
- `audio/` - local audio assets used by the playlist

## Run Locally

Open `index.html` in a browser.

## Deploy

This project is a plain static site, so it can be published on most static hosts without a build step.

### GitHub Pages

Recommended repository name: `pulse-player`

Expected Pages URL with your current GitHub username:

`https://wolfy-bot.github.io/pulse-player/`

1. Create a new GitHub repository named `pulse-player`.
2. Upload these files to the repository root.
3. In the repository settings, open **Pages**.
4. Set the source to deploy from the `main` branch root and save.
5. After GitHub finishes publishing, open `https://wolfy-bot.github.io/pulse-player/`.

### Netlify

1. Sign in to Netlify.
2. Create a new site from drag and drop or from a Git repository.
3. If asked for a publish directory, use the project root.
4. Netlify will generate a public URL immediately after deploy.

### Vercel

1. Sign in to Vercel.
2. Import the project from a Git repository or upload it as a static site.
3. Keep the framework preset as **Other** if prompted.
4. Vercel will generate a public URL after deployment.
